# TOP JavaScript Academy

Интерактивная обучающая платформа для курса **JavaScript: Старт**.

**3 дня по 270 минут · 9 занятий по 90 минут · без регистрации**

## Возможности

- 9 занятий по дням. В каждой паре 25 минут разбора тем, 45 минут в редакторе, 15 минут практики по архивным материалам и 5 минут разбора результатов.
- 27 заданий с автопроверкой по условиям из архива, 153 исходных документа Word (включая программу) и 45 комплектов стартовых файлов лабораторных.
- Встроенный JavaScript-редактор с табуляцией.
- Консоль и интерактивный HTML-предпросмотр.
- Автоматическая проверка: вывод, функции, массивы, объекты и DOM.
- Каждая проверка запускается в отдельном sandboxed iframe без доступа к origin сайта.
- Поэтапные подсказки, теория, примеры, прогресс.
- Автосохранение кода и выполненных заданий в localStorage.
- Адаптивная версия для телефона и планшета.
- Только React + TypeScript + Vite, без сервера и платных сервисов.

## Локальный запуск

Нужен Node.js версии 20+.

```bash
npm install
npm run dev
```

Открой адрес, показанный Vite.

## Проверка сборки

```bash
npm run build
npm run preview
```

## Публикация через GitHub Pages

1. Открой **Settings → Pages** этого репозитория.
2. В разделе **Build and deployment → Source** выбери **GitHub Actions**.
3. Открой вкладку **Actions** и проверь workflow «Deploy TOP JavaScript Academy».
4. После успешной публикации: https://alexeyparfenov12.github.io/top-javascript-academy/

Workflow расположен в `.github/workflows/deploy.yml` и запускается при каждом push в main.

## Учебные материалы

В разделе «План занятия» собраны темы для пары и полный список документов по теме из архива «JavaScript». Документы можно читать в браузере и скачивать в формате Word. Стартовые файлы лабораторных доступны в отдельных ZIP. Оригинальные документы сохраняют авторские примеры и решения, если они были в Word.

Редактор проверяет 27 упражнений из этих документов. Остальные условия доступны в материалах занятия для самостоятельного выполнения. Прогресс по новому набору заданий учитывается отдельно от старого пилотного набора, так как условия изменились.

## Ограничения

- Прогресс хранится на одном устройстве/в одном профиле браузера.
- Клиентская проверка образовательная: её нельзя считать защищённой экзаменационной системой.
- Для обычных циклов в редакторе действует ограничение времени выполнения. Платформа предназначена для запуска собственного учебного кода.
- Для массового преподавательского кабинета понадобится backend и отдельная песочница.
